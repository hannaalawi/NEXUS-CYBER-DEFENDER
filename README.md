# UNIMUS NEXUS Cyber Defender

Simulasi interaktif keamanan digital untuk siswa. Aplikasi ini berupa satu file statis dan dapat dipublikasikan gratis melalui GitHub Pages.

## Cara unggah ke GitHub Pages

1. Buat repository baru di GitHub, misalnya `unimus-nexus-cyber-defender`.
2. Pilih **Public**, lalu buat repository.
3. Unggah seluruh isi folder ini ke **akar repository**, terutama file `index.html`.
4. Di repository GitHub, buka **Settings** > **Pages**.
5. Pada **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/(root)`, lalu tekan **Save**.
7. Tunggu sekitar satu hingga beberapa menit. Tautan aplikasi muncul pada halaman GitHub Pages, dengan bentuk:

   `https://NAMA-USERNAME.github.io/unimus-nexus-cyber-defender/`

Tautan tersebut dapat dibuka dari ponsel maupun laptop.

## Catatan

- Tidak perlu database atau instalasi server.
- Data peserta tidak dikirim atau disimpan.
- Untuk memperbarui aplikasi, cukup unggah versi terbaru `index.html` ke repository yang sama.
